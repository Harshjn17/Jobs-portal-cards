# Jobs Portal Cards

A simple and responsive **Jobs Portal Cards UI** built with React and Tailwind CSS.

## 🚀 Features

* Job cards with company information
* Company logo
* Company name
* Job posting time
* Job role
* Salary range
* Job location
* Responsive card layout
* Reusable React Card component

## 🛠️ Tech Stack

* React
* JavaScript
* Tailwind CSS
* Vite

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Harshjn17/Jobs-portal-cards.git
```

Go into the project:

```bash
cd Jobs-portal-cards/fronted
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

## 🎯 Purpose

This project was created to practice **React components, props, array mapping, and Tailwind CSS** while building a reusable job card UI.

Job cards display:

* Company
* Role
* Salary
* Location
* Posted time
